# Design System: Realtime Chat Platform (Stitch Redesign)

## 1. Visual Theme & Atmosphere
Modern, sleek, and focused. A "Pro-Grade" dark mode environment using deep midnight blues and vibrant accent glows. The layout prioritized readability and functional density without clutter. Components use high-contrast surfaces to maintain hierarchy.

## 2. Color Palette & Roles
- **Deep Midnight (#050913)**: The foundational background color.
- **Surface Navy (#0a0f1c)**: Used for primary containers and sidebars.
- **Electric Violet (#8b5cf6)**: Primary accent for interactive elements and own-message bubbles.
- **Cyan Glow (#22d3ee)**: Secondary accent for assistant messages and secondary actions.
- **Success Green (#22c55e)**: Positive feedback, online indicators, and completed tasks.
- **Safety Amber (#f59e0b)**: Warnings and critical alerts.
- **Text Primary (#f8fafc)**: High readability for all body text.
- **Text Muted (#64748b)**: Secondary labels and timestamps.

## 3. Typography Rules
- **Font Family**: Inter or System San-Serif.
- **Headers**: Semi-bold with tight letter-spacing (-0.02em) for a modern, compact look.
- **Body**: Regular weight, optimized line-height (1.55) for comfortable long-form reading.

## 4. Component Stylings
* **Buttons**: Pill-shaped or rounded-square (12px). Interactive buttons use subtle gradients or solid background with 1px borders.
* **Cards/Containers**: Generously rounded corners (24px for panels, 18px for bubbles). Uses subtle inner borders (1px) instead of heavy shadows for depth.
* **Inputs**: Opaque dark background (#070b14) with consistent padding and focused border transitions.

## 5. Layout Principles
* **Collapsible Architecture**: Both sidebars are collapsible to maximize chat real estate.
* **Floating Header**: Minimalist header that acts as a focal point for the current partner.
* **Pinned Composer**: Fixed at the bottom with explicit horizontal alignment for tools.
* **Zero-Bleed Spacing**: Clear separation between message bubbles and control panels.
